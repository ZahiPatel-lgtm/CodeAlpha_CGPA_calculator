## CGPA Calculator System

This project is a simple CGPA Calculator developed in C++.  
The program allows users to enter the number of courses, grades and credit hours for each course. It calculates the total credits, total grade points and final CGPA automatically.

### Features
- Input grades and credit hours for multiple courses
- Calculates total credits and grade points
- Computes semester GPA/overall CGPA
- Displays individual course details
- Beginner-friendly and easy-to-understand code

### Concepts Used
- Arrays
- Loops
- Variables
- User input and output
- Arithmetic calculations
